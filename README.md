# 2026 Portfolio

Modern React portfolio website showcasing technical projects, software engineering experience, automation engineering work, and evolving frontend development skills.

## Overview

This portfolio was designed and developed to serve as a centralized space for:
- showcasing software engineering and automation projects
- highlighting professional experience and technical growth
- experimenting with reusable React component architecture
- practicing modern frontend development patterns and UI design

The site focuses on clean UI design, responsive layouts, reusable components, and engineering-oriented project presentation.

---

## Features

- Responsive React-based portfolio UI
- Reusable project card component architecture
- Dynamic project status indicators
- GitHub and demo linking
- SCSS styling and component-based organization
- Technical project showcase section
- Modern frontend design patterns

## Running Locally

Clone the repository:

```bash
git clone https://github.com/drogers14/2026-portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm start
```
